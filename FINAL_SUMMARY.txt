## 💡 TROUBLESHOOTING QUICK TIPS

| Issue | Solution |
|-------|----------|
| Backend not running | `python backend/app.py` |
| Frontend not loading | `npm start` in frontend folder |
| "Cannot reach backend" | Start backend first |
| "No employee data" | Add in "Input Data Karyawan" |
| "No face detected" | Upload clearer photo |
| Model downloading | Wait 5-10 minutes first time |
| Port 5000/3000 in use | Close other apps or change port |
