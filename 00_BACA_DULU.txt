## ⚡ QUICK START (5 MENIT)

### Step 1: Jalankan Aplikasi
```bash
cd d:\MIKROSKIL\OPERASI\deepface

# Pilih salah satu:

# A. Docker (easiest)
docker-compose up

# B. Manual - Terminal 1
cd backend
python app.py

# B. Manual - Terminal 2 (new terminal)
cd frontend
npm start
```

### Step 2: Tunggu Loading
- Backend: Lihat "Uvicorn running on http://0.0.0.0:5000"
- Frontend: Browser otomatis buka atau buka http://localhost:3000

### Step 3: Test Aplikasi
1. Klik "Input Data Karyawan"
2. Isi nama, departemen, upload foto wajah
3. Klik "✓ Tambah Karyawan"
4. Klik "Menu Absensi Karyawan"
5. Pilih karyawan, upload/ambil foto
6. Klik "✓ Verifikasi Wajah"
7. Lihat hasil: ✓ Terverifikasi atau ✗ Tidak Cocok

### Step 4: Jika Ada Error
1. Buka browser DevTools (F12)
2. Check Console tab untuk error message
3. Check backend terminal untuk server logs
4. Baca TROUBLESHOOTING.md
